CRISP-DM 六階段作業流程
1. 商業理解：由研發、行政、行銷費用與州別估算 Profit；用 MAE / MSE 與平均值基準比較。
2. 資料理解：50 筆、5 個原始欄位；檢查缺值、重複與分布，保留零值及極端值。
3. 資料準備：State one-hot 編碼後共 5 個特徵；固定 80/20 切分，補值放在 Pipeline 中。
4. 建模：scikit-learn LinearRegression；窮舉 31 個非空特徵子集，訓練集五折交叉驗證。
5. 評估：先由 CV MSE 決定排名，再顯示 Test MSE、RMSE、MAE、R² 與殘差。
6. 部署：將訓練模型係數匯出至離線介面；另保存全資料重訓的 joblib 模型供後續使用。

五種方法與互動預測均由 Python 模型匯出。資料切分及選特徵設定與老師網站未完全核對，因此結果不會完全相同。
